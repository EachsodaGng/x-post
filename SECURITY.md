# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `x-post`, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to the maintainer or report via GitHub Security Advisories tab.
3. Include details of the vulnerability, reproduction steps, and potential impact.

We will investigate and publish a patch promptly.
